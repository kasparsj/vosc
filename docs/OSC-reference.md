## Runtime Behavior

- Onset queueing: `/shading`, `/shading/passes`, and targeted resource commands are queued and flushed when onset conditions pass (`/onset`, `/onset/force`, audio onset, or Tidal note activity).
- Shading: `/shading deferred` enables deferred path; `/shading/passes` resets and rebuilds pass chains by name or id.
- MIDI: `/midi` forwards messages to MIDI input handling; `/midi/list` lists available input ports.
- Target selector semantics:

| Family | Targeting |
|---|---|
| `/tex*`, `/var*`, `/geom*`, `/shader*` | `index` / `wildcard` / `shared-name` |
| `/layer*`, `/mat*` | `index` / `wildcard` |
| top-level commands (`/layers`, `/onset`, `/midi`, `/shading`, etc.) | no target arg |

## Aliases

- `/shader/buf` -> `/shader/buffer`
- `/shader/tex` -> `/shader/texture`
- `/shader/uniform` -> `/shader/var`

## Feature-Flagged Behavior

- `/tex (gv source)` (USE_OFX_EXTREME_GPU_VIDEO) - GV source support depends on compile-time addon availability.
- `/tex (hpv source)` (USE_OFX_HPVPLAYER) - HPV source support depends on compile-time addon availability.
- `/tex (ultralight html source)` (USE_OFX_ULTRALIGHT) - Ultralight-backed HTML source support depends on compile-time addon availability.
